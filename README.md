# 🤖 Universal Super Telegram Bot (All-in-One)

Ushbu bot barcha eng mashhur va foydali funksiyalarni o'zida jamlagan universal tizimdir:

1. **📥 Universal Downloader:** Instagram, TikTok (suv belgisiz), YouTube, Pinterest, Likee, Snapchat, Telegram.
2. **🎵 Shazam & Musiqa:** Ovozli xabar, video va audio fayllardan qo'shiqni aniqlash + MP3 yuklash + qo'shiq matni (lyrics).
3. **🧠 Multi-Modal AI (Gemini):** Savol-javob, suhbat xotirasi, ovozli savollarni tushunish, rasm va PDF hujjatlar tahlili.
4. **🎨 Rasm Vositalari:** Fonni o'chirish (Remove BG), OCR (matn ajratish), rasm siqish (compress), Video -> MP3.
5. **📄 Fayl & Hujjat:** Rasm ➡️ PDF, ZIP arxivlash.
6. **✍️ Matn & Til:** Lotin ➡️ Kirill, Kirill ➡️ Lotin, Matndan Ovoz (TTS), Aqlli Tarjimon, Imlo tekshiruvchi.
7. **🛠 Kundalik Asboblar:** QR-kod yaratish va o'qish, O'zbekiston Markaziy Banki (CBU) valyuta kurslari.

---

## 🚀 Ishga tushirish

1. `.env` faylini oching va `BOT_TOKEN` hamda `GEMINI_API_KEY` ni kiriting.
2. `run_bot.bat` faylini ikki marta bosing yoki terminalda:
   ```bash
   pip install -r requirements.txt
   python main.py
   ```
